# Mansik-Santulan-Score (Mental Health Score Prediction)

## 📌 Overview
**Mansik-Santulan-Score** is a machine learning-based project designed to analyze personal, environmental, and mental wellness factors to predict individual mental health scores. The model aims to provide early insights into psychological balance and promote overall well-being.

---

## ✨ Features
* **Data Preprocessing & Cleaning:** Handles missing values, encodes categorical variables, and scales numerical features.
* **Exploratory Data Analysis (EDA):** Visualizes key relationships and correlations affecting mental health metrics.
* **Predictive Modeling:** Trains machine learning regression/classification models to accurately predict mental health scores.
* **Evaluation Metrics:** Evaluates model performance using standard metrics (e.g., RMSE, R² Score, MAE / Accuracy).

---

## 🛠️ Tech Stack
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn (e.g., Random Forest, XGBoost, Linear Models)
* **Environment:** Jupyter Notebook / Python Scripts
